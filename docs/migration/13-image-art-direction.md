# 13 - Direccion de Arte de Imagenes

Iteracion: `MEDIA-01`

## Contrato visual

- Premium inmobiliario, moderno, sobrio y confiable.
- Verde bosque dominante; ambar como detalle de marca.
- Fotografia realista y editorial; no stock generico evidente.
- Espacio negativo suficiente para texto HTML.
- Sin texto generado dentro de imagenes.
- Sin elementos que prometan servicios o infraestructura no confirmados.
- Las composiciones conceptuales deben rotularse como referenciales.

## Contrato de marca

- `logo.png` no se redibuja ni se reinterpreta.
- Los logos de proyectos se entregan como capas protegidas.
- No se modifican rostros de personas reales.
- No se agregan marcas de terceros.

## Contrato tecnico

- Hero: 16:10, master minimo 1920 x 1200.
- Proyecto: 4:3, master recomendado 1200 x 900.
- Mapa: vector preferido o raster minimo 1600 px de alto.
- AVIF y WebP para web.
- PNG para transparencia y fallback.
- JPEG/PNG para Open Graph.
