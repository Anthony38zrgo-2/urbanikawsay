# Context Handoff

Run Context GC first. Then pass:

```text
OBJECTIVE
LEGACY BASELINE
VISUAL INTENT
IN / OUT OF SCOPE
ROUTES / FEATURES
VERIFIED FACTS
MIGRATION CONTRACT
RELEVANT FILES
CONTENT / SEO CONSTRAINTS
COMPONENT / DESIGN DECISIONS
SVG REQUIREMENTS
ACCEPTANCE CRITERIA
VALIDATION COMMANDS
ROLLBACK CONDITIONS
KNOWN UNKNOWNS
DO NOT CHANGE
```

Do not pass raw investigation transcripts or force Builder to infer architecture from conversation history.
